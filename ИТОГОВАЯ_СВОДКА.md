## 🔄 Автоматическое обновление файла

### Как это работает:

1. **Система выгружает файл** в папку на MDrive
2. **Старый файл заменяется** новым (с тем же или другим именем)
3. **Дашборд каждые 60 секунд** запрашивает данные
4. **Сервер ищет файл заново** и подхватывает обновленную версию

### Преимущества:

- ✅ **Не нужно перезапускать сервер** - файл подхватывается автоматически
- ✅ **Не нужно менять config.json** - даже если имя файла изменилось
- ✅ **Всегда актуальные данные** - сервер использует последнюю версию

## 📝 Важные детали

### Формат пути в Windows:

В `config.json` используйте **двойной обратный слэш**:
```json
{
  "excelFilePath": "\\\\server\\share\\folder"
}
```

### Требования к Excel файлу:

- Формат: `.xlsx` (не `.xls`)
- Обязательные столбцы:
  - `Производственный ресурс`
  - `Дата операций`
  - `Название операции`
  - `Количество операций`
  - `Кол-во, шт`

### Порт сервера:

По умолчанию: **3000**

Если нужно изменить, отредактируйте в `server.js`:
```javascript
const PORT = 3000;  // Измените на нужный
```
