# Производственный Дашборд

Система мониторинга производственных операций с поддержкой двух логик: MOP и MULT.

## 🚀 Быстрый старт

### Windows
Запустите `start.bat` для автоматического запуска сервера.

### Linux/Mac
```bash
node server.js
```

## 📊 Доступные дашборды

После запуска откройте браузер:
- **Главная страница**: http://localhost:3000/
- **MOP Логика**: http://localhost:3000/dashboard-mop.html
- **MULT Логика**: http://localhost:3000/dashboard-mult.html

## ⚙️ Конфигурация пути к Excel файлу

### Вариант 1: Указать путь к папке или файлу в config.json

Отредактируйте файл `config.json`:

**Путь к папке (рекомендуется для автообновления):**
```json
{
  "excelFilePath": "\\\\corp.noytech.com\\MDrive\\Kuz WH\\2_Клиенты\\37_R-Mixed\\6_Отчеты и KPI\\02_PS+аналитика\\Аналитика\\Дэшборды\\Универсальный"
}
```

**Путь к конкретному файлу:**
```json
{
  "excelFilePath": "Z:\\данные\\отчет.xlsx"
}
```

**Примеры путей:**
- **Папка на сетевом диске (UNC):** `"\\\\server\\share\\folder"`
- **Папка на сетевом диске (буква):** `"Z:\\data\\production"`
- **Конкретный файл:** `"C:\\Users\\Username\\Documents\\report.xlsx"`
- **Linux папка:** `"/mnt/network/data"`

⚠️ **Важно для Windows:** Используйте двойной обратный слэш `\\` в путях.

### Вариант 2: Положить файл в папку проекта

Если `excelFilePath` пустой или путь не найден, сервер автоматически найдет первый `.xlsx` файл в папке проекта.

### 🔄 Автоматическое обновление файла

Если указан путь к **папке**, сервер будет каждый раз использовать первый найденный `.xlsx` файл в этой папке. Это удобно когда файл автоматически обновляется (заменяется) в папке - сервер всегда будет использовать актуальную версию.

## 📈 Логики дашбордов

### MOP Логика
- **Приёмка**: операция "приемка" (Кол-во, шт)
- **Размещение**: перемещения, привязка к местам, ручные перемещения (Количество операций)
- **Сборка**: пикинг MOP зона хранения мезонин (Количество операций)
- **Контроль**: контроль (Кол-во, шт)

### MULT Логика
- **Приёмка**: операция "приемка" (Количество операций)
- **Размещение**: перемещения, ручные перемещения, привязка к местам, раскладка на полки (Количество операций)
- **Сборка (пикинг)**: зона хранения MULTI (Количество операций)
- **Контроль**: контроль (Количество операций)

## 🔄 Автообновление

Дашборды автоматически обновляются каждые 60 секунд.

## 📝 Требования к Excel файлу

Файл должен содержать следующие столбцы:
- `Производственный ресурс`
- `Дата операций`
- `Название операции`
- `Количество операций`
- `Кол-во, шт`
- (опционально) Среднее время, Общее время, Длительность работы, Кол-во (уп, строк), Вес, Объем

## 🛠️ Изменение нормативов

Отредактируйте константу `NORMS` в соответствующем файле дашборда (dashboard-mop.html или dashboard-mult.html):

```javascript
const NORMS = {
    receiving: 4000,
    placement: 200,
    picking: 100,
    control: 100
};
```

## ⚠️ Важно

- **Node modules** остаются в папке проекта, не нужно устанавливать их на корпоративный диск
- Сервер использует только встроенные модули Node.js (http, fs, path)
- Все библиотеки для дашборда загружаются через CDN
- Файл Excel может находиться на любом доступном диске (локальном или сетевом)
