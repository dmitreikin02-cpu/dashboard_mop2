# История изменений - Версия 2

## [v2.0] - 2024-11-17 - Поддержка папок и автообновления

### ✨ Новые возможности

#### 1. Поддержка путей к папкам
- Теперь в `config.json` можно указать путь к **папке**, а не только к файлу
- Сервер автоматически найдет первый `.xlsx` файл в указанной папке
- Это позволяет файлу автоматически обновляться (заменяться) без изменения конфигурации

**Примеры:**
```json
{
  "excelFilePath": "\\\\corp.noytech.com\\MDrive\\Kuz WH\\Папка"
}
```

#### 2. Настроен путь к корпоративной папке
- В `config.json` по умолчанию прописан путь:
```
\\corp.noytech.com\MDrive\Kuz WH\2_Клиенты\37_R-Mixed\6_Отчеты и KPI\02_PS+аналитика\Аналитика\Дэшборды\Универсальный
```
- Готово к использованию "из коробки" - просто запустите сервер!

### 🔄 Как работает автообновление

```
Система → Выгружает файл в папку на MDrive
   ↓
Старый файл заменяется новым
   ↓
Дашборд (каждые 60 сек) → Подхватывает новый файл автоматически
```

**Преимущества:**
- ✅ Не нужно перезапускать сервер
- ✅ Не нужно менять config.json при изменении имени файла
- ✅ Сервер всегда использует актуальную версию

### 🎯 Логика работы

1. **При запуске сервера:**
   - Читается `config.json`
   - Проверяется путь `excelFilePath`

2. **Если путь - папка:**
   - Выводится сообщение: `📂 Используется папка из config.json: <путь>`
   - Поиск первого `.xlsx` файла в папке
   - Если найден: `📊 Найден Excel файл: <имя файла>`

3. **Если путь - файл:**
   - Выводится сообщение: `📊 Используется файл из config.json: <путь>`
   - Файл используется напрямую

4. **При каждом запросе данных (`/excel`):**
   - Функция `getExcelFilePath()` вызывается заново
   - Если указана папка, поиск файла происходит снова
   - Таким образом, новый файл подхватывается автоматически
