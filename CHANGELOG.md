# История изменений

## [Текущая версия] - 2024-11-17

### ✨ Добавлено

#### 1. Поддержка пути к Excel файлу на корпоративном диске
- Добавлен файл `config.json` для указания пути к xlsx файлу
- Сервер теперь может читать файлы с любого доступного диска (локального или сетевого)
- Автоматический fallback к поиску файла в папке проекта если путь не указан
- Node modules остаются в папке проекта, не требуется установка на корпоративный диск

#### 2. Вторая логика "MULT"
- Создан новый дашборд `dashboard-mult.html` с логикой MULT
- Переименован основной дашборд в `dashboard-mop.html` для ясности

**Логика MULT включает:**
- **Приёмка MULT**: операция "приемка" (Количество операций)
- **Размещение MULT**: перемещения, ручные перемещения, привязка к местам, раскладка на полки (Количество операций)
- **Сборка MULT (пикинг)**: зона хранения MULTI (Количество операций)
- **Контроль MULT**: контроль (Количество операций)

**Ключевые отличия от MOP:**
- Все метрики используют "Количество операций" вместо смеси "Кол-во, шт" и "Количество операций"
- Сборка использует "зона хранения multi" вместо "пикинг mop зона хранения мезонин"
- Размещение включает дополнительную операцию "раскладка на полки"

#### 3. Главная страница выбора логики
- Добавлена стартовая страница на http://localhost:3000/ с выбором логики
- Кнопки для быстрого перехода на MOP или MULT дашборд
- Стильный интерфейс с цветовой кодировкой (зеленый для MOP, оранжевый для MULT)

#### 4. Документация
- `README.md` - полная документация на английском
- `ИНСТРУКЦИЯ.md` - подробная инструкция на русском
- Примеры путей к файлам для разных платформ
- FAQ и решение типовых проблем

### 🎨 Особенности реализации

1. **Расположение графиков**: Одинаковое для обеих логик (2x2 сетка)
2. **Столбцы данных**: Используются те же столбцы из Excel файла
3. **Цветовая индикация**: 
   - MOP логика - зеленый индикатор
   - MULT логика - оранжевый индикатор
4. **Автообновление**: Каждые 60 секунд для обоих дашбордов
5. **Без зависимостей**: Все библиотеки загружаются через CDN

### 🛠️ Технические детали

- **Язык**: Node.js (backend), HTML5 + JavaScript ES6 (frontend)
- **Библиотеки**: Chart.js, XLSX.js, Day.js, Lodash (все через CDN)
- **Порт**: 3000 (по умолчанию)
- **Совместимость**: Windows, Linux, macOS

### 📝 Примечания

- Excel файл может находиться на любом доступном диске
- Не требуется установка node_modules на корпоративный диск
- Оба дашборда могут работать одновременно в разных вкладках браузера
- Изменения в config.json применяются при перезапуске сервера
