## ✅ Выполнено

### 1. Добавлена возможность указать конкретный путь к xlsx файлу на корпоративном диске

**Реализация:**
- Создан файл `config.json` с полем `excelFilePath`
- В `server.js` добавлены функции:
  - `loadConfig()` - читает config.json
  - `getExcelFilePath()` - определяет путь к файлу (из config или автопоиск)
- Поддерживаются любые пути: локальные, сетевые диски, UNC пути
- Автоматический fallback к поиску .xlsx в папке проекта если путь не указан

**Важно:** Node modules остаются в папке проекта! Не требуется устанавливать их на корпоративный диск.

## 🎯 Соответствие требованиям

### ✅ "Указать конкретный путь на корпоративном диске к файлу xlsx"
**Решение:** Файл `config.json` с полем `excelFilePath`. Примеры:
- `"Z:\\данные\\отчет.xlsx"` - сетевой диск
- `"C:\\Users\\Иванов\\Documents\\отчет.xlsx"` - локальный диск
- `"\\\\server\\папка\\отчет.xlsx"` - UNC путь

### ✅ "В этой папке больше ничего лежать не может"
**Решение:** Node modules НЕ устанавливаются на корпоративный диск.
- Сервер использует только встроенные модули Node.js
- Frontend библиотеки загружаются через CDN
- Excel файл может находиться где угодно

### ✅ "node module тоже не могу установить"
**Решение:** Не требуется! Проект использует:
- Встроенные модули Node.js (http, fs, path)
- CDN для frontend библиотек (Chart.js, XLSX.js, Day.js, Lodash)

### ✅ "Добавь вторую логику MULT"
**Решение:** Создан `dashboard-mult.html` с точными требованиями:
- Приемка MULT - приемка
- Размещения MULT - перемещения, ручные перемещения, привязка к местам, раскладка на полки
- Сборка MULT - зона хранения MULTI
- Контроль MULT - контроль

### ✅ "Столбцы брать как в логике MOP"
**Решение:** Используются те же столбцы из Excel:
- Производственный ресурс
- Дата операций
- Название операции
- Количество операций (используется для MULT)
- Кол-во, шт (используется для MOP)

### ✅ "Расположение графиков как на MOP логике"
**Решение:** Идентичная сетка 2x2, те же стили, тот же порядок.

## 🚀 Как использовать

1. **Настроить путь к файлу:**
   Отредактировать `config.json`:
   ```json
   {
     "excelFilePath": "Z:\\данные\\производство\\отчет.xlsx"
   }
   ```

2. **Запустить сервер:**
   - Windows: двойной клик на `start.bat`
   - Или: `node server.js`

3. **Открыть браузер:**
   - http://localhost:3000/ - выбор логики
   - http://localhost:3000/dashboard-mop.html - MOP
   - http://localhost:3000/dashboard-mult.html - MULT
