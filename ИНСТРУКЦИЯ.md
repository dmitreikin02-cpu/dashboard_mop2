# 📋 Инструкция по настройке дашбордов MOP и MULT

## 🎯 Быстрый старт

1. **Запустите сервер**
   - Windows: двойной клик на `start.bat`
   - Или вручную: `node server.js`

2. **Откройте браузер**
   - Перейдите на: http://localhost:3000
   - Выберите нужную логику (MOP или MULT)

## ⚙️ Настройка пути к Excel файлу

### Способ 1: Указать путь на корпоративном диске

Откройте файл `config.json` и укажите путь к **папке** или к **файлу**:

**📂 Путь к папке (рекомендуется для автообновления):**
```json
{
  "excelFilePath": "\\\\corp.noytech.com\\MDrive\\Kuz WH\\2_Клиенты\\37_R-Mixed\\6_Отчеты и KPI\\02_PS+аналитика\\Аналитика\\Дэшборды\\Универсальный"
}
```

**📄 Путь к конкретному файлу:**
```json
{
  "excelFilePath": "Z:\\данные\\производство\\отчет.xlsx"
}
```

**Важно:** В Windows используйте двойной обратный слэш `\\`

**Примеры путей:**
- **Папка UNC:** `"\\\\corp.noytech.com\\MDrive\\Папка"`
- **Папка на диске:** `"Z:\\данные\\производство"`
- **Конкретный файл:** `"C:\\Users\\Иванов\\Documents\\отчет.xlsx"`
- **UNC файл:** `"\\\\server\\папка\\отчет.xlsx"`

### Способ 2: Положить файл в папку проекта

Если оставить `excelFilePath` пустым, сервер автоматически найдет первый `.xlsx` файл в папке проекта.

### 🔄 Как работает автообновление

Если вы указали путь к **папке** (а не к файлу), сервер каждый раз при запросе данных будет искать первый `.xlsx` файл в этой папке.

**Преимущества:**
- ✅ Файл может автоматически заменяться в папке (например, выгружаться из системы)
- ✅ Не нужно менять config.json при изменении имени файла
- ✅ Сервер всегда использует актуальную версию файла

**Пример использования:**
1. Система автоматически выгружает файл в папку на MDrive
2. Старый файл заменяется новым
3. Дашборд при следующем обновлении (каждые 60 сек) подхватывает новые данные

## 📊 Различия между логиками

### MOP Логика
- **Приёмка**: операция "приемка" (Кол-во, шт)
- **Размещение**: перемещения, привязка к местам, ручные перемещения (Количество операций)
- **Сборка**: пикинг MOP зона хранения мезонин (Количество операций)
- **Контроль**: контроль (Кол-во, шт)

### MULT Логика  
- **Приёмка**: операция "приемка" (Количество операций)
- **Размещение**: перемещения, ручные перемещения, привязка к местам, раскладка на полки (Количество операций)
- **Сборка (пикинг)**: зона хранения MULTI (Количество операций)
- **Контроль**: контроль (Количество операций)

## 🔧 Изменение нормативов

Откройте соответствующий файл дашборда (dashboard-mop.html или dashboard-mult.html) и найдите секцию:

```javascript
const NORMS = {
    receiving: 4000,
    placement: 200,
    picking: 100,
    control: 100
};
```

Измените значения по необходимости и сохраните файл.

## ❓ Частые вопросы

**Q: Где должны находиться node_modules?**  
A: Node modules не нужны! Сервер использует только встроенные модули Node.js, а frontend библиотеки загружаются через CDN.

**Q: Файл Excel может находиться на другом диске?**  
A: Да, укажите полный путь в config.json. Главное чтобы у пользователя был доступ к этому диску.

**Q: Как часто обновляются данные?**  
A: Дашборд автоматически перезагружает данные каждые 60 секунд.

**Q: Можно ли использовать оба дашборда одновременно?**  
A: Да, откройте два окна браузера и загрузите разные дашборды.

## 📞 Поддержка

При проблемах проверьте:
1. Правильность пути к Excel файлу в config.json
2. Наличие доступа к файлу (права на чтение)
3. Формат файла (должен быть .xlsx)
4. Наличие требуемых столбцов в Excel файле
